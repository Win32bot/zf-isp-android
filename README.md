# ZF-ISP для Android

Прошивальщик AVR-микроконтроллеров с телефона через USB OTG для программатора **ZhiFeng USBISP** (HID **VID 03EB / PID C8B4**, родное ПО — PROGISP). Android-версия [ZF-ISP для Windows](https://github.com/Win32bot/zf-isp).

## Что нужно

- Android 7.0 и новее с поддержкой **USB OTG** (USB Host);
- OTG-переходник (USB-C/micro-USB → USB-A);
- программатор, который определяется как HID `03EB:C8B4` (строка производителя `zhifengsoft`). Другие программаторы не поддерживаются.

Питание платы: телефон питает программатор через OTG, но ток ограничен — плату с заметным потреблением лучше питать отдельно.

## Возможности

- автоопределение чипа по сигнатуре — 128 сигнатур (176 моделей) AVR с ISP: ATmega, ATtiny, AT90CAN/PWM/USB, AT90S;
- фьюзы Low/High/Extended и Lock: hex или галочки по битам с названиями, запись с проверкой;
- защита: нельзя снять **SPIEN** и включить **RSTDISBL**, предупреждения для **DWEN** / **JTAGEN**;
- Flash: стирание, запись, проверка, чтение в Intel HEX (в т.ч. > 128 КБ);
- EEPROM: запись с проверкой, проверка, чтение в файл;
- 5 скоростей ISP, прогресс с оставшимся временем, «Стоп», журнал;
- приложение открывается само при подключении программатора.

## Работа

1. Подключите программатор через OTG — Android предложит открыть ZF-ISP, разрешите доступ к USB-устройству.
2. **«Подключить / прочитать»** — модель чипа и фьюзы. Для нового чипа (1 МГц с завода) выберите скорость **5**.
3. Выберите HEX-файл и нажмите **«Прошить»** (стирание → запись → проверка).
4. Lock-биты ставьте **последним** шагом.

Во время операции экран не гаснет. Запись 256 КБ занимает несколько минут (как и в Windows-версии).

## Сборка

Нужны JDK 17+ и Android SDK (platform 36):

```bash
./gradlew assembleRelease          # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest        # тесты: кодирование ISP-команд сверяется с эталонами Windows-версии
```

Таблица чипов `app/src/main/assets/chips.json` экспортирована из `chips_db.py` Windows-версии (avrdude.conf + bits.xml из AVRDUDESS).

## Протокол

HID feature report ID 1, 8 байт, передаётся через `controlTransfer` (SET_REPORT/GET_REPORT):

| | Пакет |
|---|---|
| вход в ISP | `01 0D 01 spd 20 A0 40 C0`, затем `01 0D 00 spd 20 A0 40 C0` |
| ISP-команда | `01 0E b0 b1 b2 b3 00 04` → ответ GET_REPORT, байты 0..3 |
| выход | `01 0B 01 00 00 00 00 00` |

Команда выполняется программатором только при чтении ответа.
